- Trained a real-time gesture recognition model with Python, a convolutional neural network (CNN) and OpenCV.
- Collected and prepared a custom image dataset by hand to train the network.
- Connected the system to an Arduino microcontroller over serial, so each classification appears immediately on an external LCD screen.
